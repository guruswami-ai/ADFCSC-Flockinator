Chapter 1

Set up your Kali laptop

You need two things on your laptop: a way to flash firmware onto the board, and a serial monitor to talk to it once it is running. Both are a couple of commands away on Kali.

You will install esptool (writes firmware over USB) and picocom (a serial terminal). PlatformIO is optional — only needed if you want to build the firmware from source rather than flash the ready-made binary.

1.1 Update and install the tools

Open a terminal and run:

# refresh the package index, then install Python tooling and a serial monitor
sudo apt update
sudo apt install -y python3-pip pipx picocom

# esptool flashes the board; pipx keeps it in its own isolated environment
pipx install esptool

# OPTIONAL — only if you want to compile the firmware yourself
pipx install platformio

If pipx prints a note about your PATH, run pipx ensurepath and open a new terminal so esptool is found.

Why esptool and picocom? The ESP8266 speaks a simple flashing protocol over its USB serial chip — esptool is the standard client for it. Once the firmware runs, the board just prints text and reads text over the same serial port, so any serial terminal works; picocom is small and reliable. minicom or pio device monitor are fine alternatives.

1.2 The USB-serial driver

Almost all of these boards use a CH340 USB-to-serial chip. Kali already ships the matching ch341 kernel driver, so there is usually nothing to install — when you plug the board in, a device called /dev/ttyUSB0 appears. You will confirm this in the next chapter.

If your board instead uses a CP2102 or FTDI chip, those drivers are built into Kali too; the device may appear as /dev/ttyUSB0 or /dev/ttyACM0.

1.3 Let yourself use the serial port

By default only root may open serial ports. Add your user to the dialout group once, so you do not need sudo every time:

sudo usermod -aG dialout "$USER"

Group changes only take effect after you log out and back in (or reboot). Until then you will get Permission denied on the port — either re-login, or prefix commands with sudo for now.

Checkpoint

You should now be able to run each of these without an error:

esptool version          # prints a version number
picocom --help          # prints usage

If both work, your laptop is ready. Next you will connect and flash the board.
