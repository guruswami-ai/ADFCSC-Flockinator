Handbook · Browser flasher

Flash from your browser

No toolchain, no install — ESP Web Tools flashes the board straight from Chrome or Edge over WebSerial, using the same prebuilt firmware as the command-line path. It works entirely on the lab network; nothing is downloaded from the internet.

Two requirements, or the button won't work:

  • A desktop Chrome or Edge browser (WebSerial isn't in Firefox or Safari, or on mobile).
  • This page must be opened over http://localhost or https — not as a file:// path. Browsers only allow WebSerial in a secure context.

Serve it, then open it

From a terminal, in the root of this repo, start a tiny local web server and open the page it serves:

# in the repository root (the folder that contains firmware/ and docs/)
python3 -m http.server 8000

# then open this in Chrome or Edge:
http://localhost:8000/docs/handbook/flasher/

Serving from the repo root lets the flasher reach the firmware in firmware/prebuilt/. localhost counts as a secure context, so WebSerial is allowed.

Flash

This browser can't flash — use desktop Chrome or Edge. Open this page over http://localhost or https (not a file:// path). Board plugged into a USB-A port? Then click, and pick its serial port when prompted.
  1. Plug the board into a USB-A port (see chapter 2 for the power trap).
  2. Click Flash my ESP8266.
  3. In the browser's port chooser, pick the board's serial port (often labelled CH340 or USB-SERIAL), and allow access.
  4. Let it erase and write — it takes a minute. When it reports success, the board reboots into the tool.
  5. Close the dialog and open a serial monitor at 115200 baud (picocom -b 115200 /dev/ttyUSB0) to continue with chapter 5.

Nothing to pick in the port chooser? It's almost always the cable or port, not the browser — a USB-A port and a real data cable (not charge-only). Same checklist as chapter 2.

Prefer the command line? The browser flasher writes the exact same binary as esptool — if WebSerial gives you trouble, fall back to chapter 2, Path A.

Browser flashing is powered by ESP Web Tools (Apache-2.0), vendored into this repo so it runs offline.
